Version: 0.3.0
Date: 2026-11-01
  Changes:
    - Plan splits can match usage: every factory in the split runs at the same share of its built copies (two ore mines, say), so the shares follow copies, factory edits and new factories making the item. New plan splits start this way; untick "Match usage" in the split window to set the shares by hand. Existing splits stay as they were. In the plan a split that matches usage is marked "match".
    - A sink has a Scale from 0 to 1 (a slider in the sink editor): how much of its rates the plan delivers, 0 to keep it in the plan asking for nothing. The plan row shows it ("sink ×0.5") and the sink's rates at that scale.
    - The plan table sorts afresh when you come back from the editor, statistics or a split window; it keeps its order only while you work in it.
    - Icons in the plan do something when clicked: an item opens it in Statistics, a split's icons open the split.
    - A split's icons in the plan show whole percents; the tooltip keeps the exact share.
  Bugfixes:
    - The basic belt shows its icon again: on a yellow-belt base no flow showed a belt icon.
---------------------------------------------------------------------------------------------------
Version: 0.2.0
Date: 2026-10-29
  Changes:
    - One plan window instead of tabs: sinks, plan splits and factories in one table, each with its recipe. The factory editor, statistics and a plan split open in their own window in its place.
    - One window size (960 x 680); the size toggle is gone.
    - The plan shows copies against the need ("2 of 3.05") and what is still to build (one decimal, or a tick when covered); rows keep their order while the window is open.
    - The plan is closed: no more "comes from outside the plan"; fixed copies are gone (old saves are migrated).
    - Choices to make (splits) come first in the problem list, which shows a few rows and the rest on demand.
    - Sinks show their items; the sink editor shows item names and a custom name field only where needed.
    - The editor lists items in one table with column headers, says why Save is disabled, and asks before closing with unsaved changes. Recapture hides the windows and shows a hint.
    - Plain statuses (Balanced, Needs a split, Can't balance); Capture is the first button; an empty plan explains the three steps.
  Bugfixes:
    - Imported strings are checked field by field; a broken one no longer causes errors later, and a failed import adds nothing.
    - An unchanged sink no longer counts as unsaved when opened.
    - Changing the rate unit updates the open editor and statistics.
    - Show on map from the plan no longer closes the editor.

Version: 0.1.0
Date: 2026-10-28
  Features:
    - First release: capture minifactories from the map, balance them exactly, and plan how many copies of each the base needs.
    - Rates read from the game, including modules, beacons and productivity research.
    - Plan, Factories, Items and Splits tabs; sinks for fixed demands; belt checks.
    - Shared live in multiplayer, with private drafts, an edit log and export/import strings.
