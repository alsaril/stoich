Version: 0.4.0
Date: 2026-11-13
  Features:
    - Every surface has its own plan. The window opens on the plan of the surface you are on, or the one the map shows; a selector in its title bar switches to another (every planet, and any other surface once something was captured there). A capture goes to the plan of the surface it was made on. The plan of an older save becomes the plan of Nauvis.
    - A void and an import in every plan (the Void and Import buttons open them, made on first use): lists of items whose rates the plan balance sets. A void takes whatever the plan has left over, an import brings in whatever is missing; nothing extra is made to be voided, and the factories make what they can before anything is imported. A problem row offers Void it or Import it in one click.
    - New recipe: a factory of one recipe on a machine, without building it (a recycler for one item, say). The recipe is picked by item, its recycling first, or directly; one copy is that many machines.
    - Module slots and beacons in the recipe dialog (New recipe, and Add recipe in the editor): modules for each slot, the beacon count, type and modules. The dialog shows the resulting speed and productivity, worked out as the game does (normal quality).
    - When the plan can't balance, the problem list says which items would close it, instead of every item of the contradiction: "Ice: 42.5/min left over", with the items that would do instead (the water or light oil it becomes), Void it, Add sink or Import it. A surplus is preferred over a shortage, voided where it comes out, and never with a factory running backwards.
  Changes:
    - The plan's problem list scrolls in a pane of its own under a height limit, so the plan table stays in view however many problems there are.
    - Export and import of strings are icon buttons at the end of the toolbar, so "Import" means one thing there; toolbar buttons are as wide as their captions.
    - The recipe dialog's productivity field is extra productivity now: research productivity is added by itself.
    - A plan split with an import sets its shares by hand (an import has nothing built to match), starting with all of the item imported.
    - The edit log shows the surface of each entry when several surfaces have plans.
  Bugfixes:
    - A recipe with many outputs (scrap recycling) shows its input in the plan's recipe column again: outputs took every slot.

Version: 0.3.0
Date: 2026-11-01
  Changes:
    - Plan splits can match usage: every factory in the split runs at the same share of its built copies (two ore mines, say), so the shares follow copies, factory edits and new factories making the item. New plan splits start this way; untick "Match usage" in the split window to set the shares by hand. Existing splits stay as they were. In the plan a split that matches usage is marked "match".
    - A sink has a Scale from 0 to 1 (a slider in the sink editor): how much of its rates the plan delivers, 0 to keep it in the plan asking for nothing. The plan row shows it ("sink ×0.5") and the sink's rates at that scale.
    - The plan table sorts afresh when you come back from the editor, statistics or a split window; it keeps its order only while you work in it.
    - Icons in the plan do something when clicked: an item opens it in Statistics, a split's icons open the split.
    - A split's icons in the plan show whole percents; the tooltip keeps the exact share.
  Bugfixes:
    - The basic belt shows its icon again: on a yellow-belt base no flow showed a belt icon.

Version: 0.2.0
Date: 2026-10-29
  Changes:
    - One plan window instead of tabs: sinks, plan splits and factories in one table, each with its recipe. The factory editor, statistics and a plan split open in their own window in its place.
    - One window size (960 x 680); the size toggle is gone.
    - The plan shows copies against the need ("2 of 3.05") and what is still to build (one decimal, or a tick when covered); rows keep their order while the window is open.
    - The plan is closed: no more "comes from outside the plan"; fixed copies are gone (old saves are migrated).
    - Choices to make (splits) come first in the problem list, which shows a few rows and the rest on demand.
    - Sinks show their items; the sink editor shows item names and a custom name field only where needed.
    - The editor lists items in one table with column headers, says why Save is disabled, and asks before closing with unsaved changes. Recapture hides the windows and shows a hint.
    - Plain statuses (Balanced, Needs a split, Can't balance); Capture is the first button; an empty plan explains the three steps.
  Bugfixes:
    - Imported strings are checked field by field; a broken one no longer causes errors later, and a failed import adds nothing.
    - An unchanged sink no longer counts as unsaved when opened.
    - Changing the rate unit updates the open editor and statistics.
    - Show on map from the plan no longer closes the editor.
